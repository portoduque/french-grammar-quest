# O que cada ferramenta faz

| Ferramenta | Função curta |
|---|---|
| pre-commit | Executa verificações antes de aceitar um commit local. |
| Formatter | Padroniza o formato do código. |
| Linter | Encontra erros comuns e más práticas. |
| Type checker | Encontra inconsistências de tipos antes da execução. |
| Testes | Verificam comportamento e evitam regressões. |
| Gitleaks | Detecta tokens, chaves e segredos no Git. |
| Semgrep CE | SAST: procura padrões de código vulnerável. |
| Trivy | Procura CVEs, dependências vulneráveis e problemas em IaC/containers. |
| GitHub Actions | Executa os checks automaticamente em runners do GitHub. |
| Dependabot | Abre PRs para atualizar dependências e GitHub Actions. |
| SonarQube Cloud | Mede qualidade/manutenibilidade e problemas estáticos. |
| Playwright | Testa fluxos reais no navegador. |
| OWASP ZAP | Escaneia a aplicação web rodando em staging. |
