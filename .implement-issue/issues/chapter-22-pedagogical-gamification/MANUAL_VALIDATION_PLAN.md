## 2. Rota de Exercícios: `/exercises/ch22-ex01` a `ch22-ex07`
- **Exercice 22.1 (`ch22-ex01`)**:
  - Motor: `translation`.
  - Q1: `Ta grand-mère est (French)? —Non, elle est (Italian).`
  - Resposta aceita: `Ta grand-mère est française? —Non, elle est italienne.` (ou `française, italienne`).
  - Q4: `Il porte ses chaussures (black)? —Non, il porte des chaussures (navy blue).` ➔ `Il porte ses chaussures noires? —Non, il porte des chaussures bleu marine.`
- **Exercice 22.2 (`ch22-ex02`)**:
  - Motor: `fill_blank` com botões táteis (chips).
  - Q1: `Les antiquités sont _________.` ➔ selecionar chip `vieilles`.
  - Q2: `Mon chat est _________.` ➔ selecionar chip `adorable`.
  - Q5: `Sa nouvelle histoire est _________.` ➔ selecionar chip `folle`.
- **Exercice 22.3 (`ch22-ex03`)**:
  - Motor: `fill_blank`.
  - Q1: `Patrick est français. Sonia est _________.` ➔ `française`.
  - Q4: `Patrick est beau. Sonia est _________.` ➔ `belle`.
  - Q7: `Patrick est fou. Sonia est _________.` ➔ `folle`.
  - Q9: `Patrick est roux. Sonia est _________.` ➔ `rousse`.
- **Exercice 22.4 (`ch22-ex04`)**:
  - Motor: `translation`.
  - Q3: `Ce vin-ci est (better) que ce vin-là.` ➔ `Ce vin-ci est meilleur que ce vin-là.`
  - Q6: `Arnaud a (as much) argent que vous?` ➔ `Arnaud a autant d’argent que vous?` (ou `autant d'argent`).
  - Q7: `Ce prix est (the best)!` ➔ `Ce prix est le meilleur!`
- **Exercice 22.5 (`ch22-ex05`)**:
  - Motor: `sentence_rewrite`.
  - Q1: `Charlotte/Lucie/grande/+` ➔ `Charlotte est plus grande que Lucie.`
  - Q2: `Charles/Xavier/drôle/=` ➔ `Charles est aussi drôle que Xavier.`
  - Q3: `Véronique/Sébastien/optimiste/–` ➔ `Véronique est moins optimiste que Sébastien.`
- **Exercice 22.6 (`ch22-ex06`)**:
  - Motor: `translation`.
  - Q1: `It’s a good idea.` ➔ `C’est une bonne idée.`
  - Q2: `They bought an old house in Normandy.` ➔ `Ils ont acheté une vieille maison en Normandie.`
  - Q5: `Her aunt loves old French songs.` ➔ `Sa tante aime les vieilles chansons françaises.`
  - Q7: `Norway is smaller than France.` ➔ `La Norvège est plus petite que la France.`
- **Exercice 22.7 (`ch22-ex07`)**:
  - Motor: `matching` (Correspondência de colunas).
  - Q1: `Il travaillait ici dans le passé. ➔ e. C’est l’ancien directeur.`
  - Q2: `Ils n’ont pas d’argent. ➔ d. Ils sont pauvres.`
  - Q3: `Il n’a pas de chemise à porter. ➔ a. Elles sont toutes sales.`
  - Q4: `C’est une femme grande. ➔ b. Elle mesure 1,80 m.`
  - Q5: `Elle est tombée. ➔ c. Son pauvre genou !`
